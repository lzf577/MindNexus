# 思维枢纽 - 智能桌面思维导图平台

## 一、项目定位与概述
“思维枢纽”是一款面向桌面操作系统的高性能、轻量级、无界画布智能思维导图工具。

系统的核心定位是协助用户快速捕捉瞬时灵感、梳理知识体系、构建清晰的逻辑骨架。系统不仅具备极速顺滑的键盘制图与画布漫游交互，更深度融合了多模态人工智能视觉识别与文档解析技术，能够实现从草图照片、白板板书、文档截图到结构化导图的瞬间生成。

---

## 二、核心业务与功能特性

### （一）极速流利的键盘制图交互
1. **单键即刻分支**：
   - 选中节点后按下**制表键**（Tab），极速生成并聚焦右侧子节点；
   - 按下**回车键**（Enter），瞬间生成并选中同级节点；
   - 配合**删除键**（Delete）或**退格键**（Backspace），可快速批量移除无效节点；
   - 按下**退出键**（Esc），即刻退出编辑状态并恢复全局选择模式。
2. **零点击无缝输入**：
   - 选中节点后无需双击，直接敲击键盘即可实时录入文字，极大减少构思打断感。
3. **节点复制、剪切与黏贴**：
   - 选中节点后按下**控制键+C**（Ctrl+C），将节点及其完整子树复制至系统剪贴板；
   - 选中节点后按下**控制键+X**（Ctrl+X），将非根节点及其完整子树安全剪切至剪贴板并从当前拓扑中移除，支持完整的撤销（Ctrl+Z）防误删；
   - 选中目标节点后按下**控制键+V**（Ctrl+V），将剪贴板中的节点子树作为新子节点瞬间黏贴，实现节点分支在画布上的极速迁移与重构。
4. **弹性框选与批量管控**：
   - 画布空白处按住鼠标左键即可拉出弹性框选矩形；
   - 支持配合键盘**控制键**（Ctrl）或**换档键**（Shift）进行离散多选，支持批量拖曳移动、批量调整样式与批量删除。

### （二）无界画布与自适应视图引擎
1. **无界漫游与精准缩放**：
   - 支持按住鼠标中键或右键全向拖拽实现超大视野漫游；
   - 配合控制键与鼠标滚轮，实现以鼠标光标所在点为中心的无损平滑缩放。
2. **自适应树状防重叠算法**：
   - 具备高效的树状排版机制，子节点自动居中并向右侧舒展；
   - 连线采用平滑平行的三次贝塞尔曲线算法，保证节点与连线永不交叉重叠。
3. **自由逻辑关联线**：
   - 支持在非直接父子关系的任意两个节点之间，自主绘制带有箭头的网状逻辑关系线，支持虚线、实线、线宽与颜色的自由设定。

### （三）多模态人工智能智能转换
1. **多模态图像识别成图**：
   - 能够直接加载手绘导图照片、白板板书翻拍、技术文档截图或便携式文档页面；
   - 调度后台视觉大语言模型接口，深度分析图像中的层级逻辑，自动提取核心提纲，一键无缝还原生成原生节点树。
2. **长篇文本结构化解析**：
   - 支持将无序的长篇文本材料交由大模型提炼，瞬间转化为层级分明的思维导图。

### （四）开箱即用的专业模板与主题体系
1. **四大预设行业模板**：
   - 内置软件工程、项目管理、读书笔记、头脑风暴四大高频业务骨架，一键初始化完整导图。
2. **专属视觉主题矩阵**：
   - 提供极客绿、活力橙、羊皮纸黄、灵动紫等多套精调配色；
   - 独立支持节点背景填充色、圆角弧度、外框轮廓描边、文字字体字号以及连线样式的个性化渲染。

### （五）全格式数据兼容与智能交互体系
1. **工程持久化与序列化**：
   - 支持专属工程格式（.mnx）及通用结构化对象格式（.json）保存与读取；
   - 支持导出为轻量级标记文本格式（.md）与可扩展标记语言格式（.xml）。
2. **全格式文件拖拽智能识别**：
   - 支持将导图工程文件（.mnx）、结构化数据文件（.json）、多格式视觉图像（PNG/JPG/BMP/WEBP）、便携文档（PDF）以及各种纯文本与源码文件（TXT/MD/PY/C/CPP/HTML/CSS/JS等）直接拖拽入画布窗口；
   - 系统自动判别文件属性类型，一键调度原生解析引擎或多模态大语言模型智能提炼转换。
3. **最近目录全局记忆机制**：
   - 所有文件交互对话框（包括打开、另存为、AI导入及格式导出）全面接入最近使用目录记忆栈；
   - 自动持久化记忆用户最近一次成功访问、保存或导入的目录路径，再次唤起文件选择器时自动精准定位。
4. **高保真矢量打印与图像输出**：
   - 支持自动裁切边缘多余空白，导出为超高清无损便携式矢量文档（PDF）；
   - 支持输出高分辨率位图图片（PNG/JPG），便于分发汇报与归档展示。

## 三、系统架构与技术选型

1. **核心开发语言**：基于现代化高级脚本编程语言（Python 3.10+）。
2. **图形界面与引擎**：基于跨平台图形界面应用框架（PySide6），依托二维图形视图与场景体系（QGraphicsView / QGraphicsScene）实现高性能矢量图形渲染与精准事件分发。
3. **数据模型驱动**：采用解耦的树状节点模型（NodeModel），支持完整的序列化与反序列化，内部维护撤销重做堆栈。
4. **智能处理流水线**：集成多模态大语言模型服务与文档渲染组件，保障多格式数据智能解析。
5. **打包分发机制**：支持通过独立程序打包工具（PyInstaller）生成视窗系统免安装可执行程序。

## 四、工程核心模块结构说明

```text
MindNexus/
├── main.py               # 程序入口与调度核心，承载主窗口装配、全局菜单栏与系统配置
├── models.py             # 数据模型模块，定义树状结构节点实体、层级计算与数据序列化
├── view.py               # 画布视图模块，负责无界漫游、缩放、框选与历史撤销重做管理
├── items.py              # 图形组件模块，封装节点图元、文本编辑图元与贝塞尔曲线连线
├── import_engine.py      # 智能导入引擎，负责图像处理、文档解析与大语言模型通信
├── template_data.py      # 场景模板数据模块，预置各类业务骨架与主题配色配置
├── settings.json         # 系统配置文件，持久化存储大模型服务接口与参数配置
├── test_tab.py           # 自动化测试脚本，用于验证节点快捷键与交互逻辑
├── MindNexus.spec        # 桌面端可执行程序自动化打包构建配置文件
└── readme.md             # 工程说明与架构技术规范自述文件
```

## 五、运行与打包指南

### 1. 运行环境配置
确保已安装 Python 3.10 或更高版本，并在终端安装项目所需依赖：
```bash
pip install PySide6 pymupdf openai
```

### 2. 启动应用程序
在工程根目录下执行主入口程序：
```bash
python main.py
```

### 3. 构建独立桌面执行程序
在工程根目录下执行打包命令即可生成独立运行的可执行程序：
```bash
pyinstaller --clean MindNexus.spec
```
